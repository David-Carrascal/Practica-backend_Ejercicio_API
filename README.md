 API CRUD de Usuarios - FastAPI + PostgreSQL

Proyecto desarrollado como ejercicio de estudio de FastAPI, SQLAlchemy y Pydantic.

## Tecnologías utilizadas

- Python 3.14
- FastAPI
- SQLAlchemy 2.0
- PostgreSQL
- Pydantic v2
- Uvicorn

## Funcionalidades

- Crear usuarios (POST)
- Consultar usuarios (GET)
- Actualizar usuarios (PUT)
- Eliminar usuarios (DELETE)
